# 介绍

这是我的个人博客网站，与2020年1月28日建成并发布。其中，我导入了一些我以前写的的优秀随笔，撰写了与现在编程与反编译相关的技术文章。在这个网站中，我会给大家呈现出我的最好内容，也会分享一些好文章。博客网站是一个很有趣的东西，有了它，就有了生活感；有了它，就有了时间感；有了它，就有了幸福感；有了它，就有了存在感。

我离开了我的诸多博客，创建一个自己的网站，现在正式来到这里，发布第1篇（文章其实是第二篇，第一篇是关于自我介绍的）。

# 缘起

我从没有博客开始，搬家到微信朋友圈（更专注生活），再搬到[字里行间](zi.com)软件（专注于写作），再搬到[CSDN](csdn.net)（专注于研究技术），原本想定居于此，但是最近发布了一个关于破解（反编译）的技术文章，审核却没有通过，因为CSDN出的新规“暂时不允许发布破解、激活类的文章”。这样也有道理，毕竟要保护开发者的版权，避免一些人看了这些文章误入歧途，做起盗版。CSDN帮助我提升计算机技术水平，我感谢CSDN，但是这条规定却不能给我自由的空间——我想，我应该搬家了。

我想把博客搬到[吾爱破解](52pojie.cn)，但是只局限于技术（吾爱破解账号现在有了：@TLHorse）；我想把博客搬到[简书](jianshu.com)，但是养一个账号太难；我想把博客搬到[新浪](blog.sina.com.cn)，但是根本就无法与VIP竞争；我想……无论是什么网站，都与自己的心愿差那么一点点。因此，我选择了自己建一个博客。这不仅可以提高我的写作水平，还可以练一下自己的技术。

# 反馈与改进
人外有人，天外有天。这个博客肯定多多少少有一些缺陷，欢迎联系我，批评指正。可能是关于：

*   界面不美观；
*   界面不协调，布局不恰当；
*   界面互动不好；
*   文章内容需要改进；
*   图片过期、显示不清、无法显示、显示缓慢；
以上只是列了几条批评指正或提出建议的方面。坐在屏幕前的你，看到哪里不顺眼，也欢迎告诉我原因、吐槽一番。
